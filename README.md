# 📊 Executive Sales Performance Dashboard – Power BI Project

## 📌 Project Overview
This project presents an interactive Executive Sales Performance Dashboard developed using Microsoft Power BI. The dashboard provides a comprehensive analysis of sales, profit, quantity, and discount trends across multiple years. It helps business stakeholders monitor performance, compare results, and identify growth opportunities.

## 🎯 Objectives
- Monitor overall sales performance
- Analyze profit and loss patterns
- Compare sales performance by category, region, and city
- Evaluate sales manager performance
- Track monthly, weekly, and yearly sales trends
- Support data-driven business strategy

## 🛠️ Tools & Technologies Used
- Microsoft Power BI
- Power Query (Data Cleaning & Transformation)
- DAX (Data Analysis Expressions)
- Data Visualization Techniques

## 📈 Dashboard Features

### ✅ Sales Pulse
- Overview of total sales, profit, quantity, and order count
- Category-wise and sales manager performance
- Interactive filters for better data exploration

### ✅ Sales Leadership Insights
- Sales and profit comparison by state and sales manager
- Positive and negative profit identification
- Detailed product and customer performance analysis

### ✅ Profit & Loss Landscape
- Monthly and weekly profit trends
- Category-based loss analysis
- Sales distribution across cities and regions

### ✅ Sales Timeline & Targets
- Year-wise category sales performance
- Monthly sales and profit comparison
- Sales target tracking and performance evaluation

## 📊 Key Insights
- Identifies high-performing sales managers and regions
- Detects categories and locations generating losses
- Tracks seasonal and yearly sales performance
- Helps optimize business strategy using visual analytics
